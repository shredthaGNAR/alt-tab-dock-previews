AltTab + DockAltTab, in one app

Window previews for your Dock.

Hover any running app in the macOS Dock to see its windows, just like on Windows. It's built straight into AltTab, so there's no second app to run.

One app instead of two.

DockAltTab used to drive a special build of AltTab from the outside, sending it AppleScript commands as your pointer moved. This build moves DockAltTab's logic inside AltTab itself.

Before

AltTab + DockAltTab

  • Two apps to install, update and grant permissions to
  • Every hover sent an AppleScript command to AltTab
  • Window counts polled over AppleScript every 1–2 seconds
  • Hovering an app with nothing to show could crash AltTab
Now

AltTab Dock Previews

  • One app with one set of permissions
  • Previews are shown directly, with no AppleScript in between
  • Window counts read the moment you click
  • Only the Dock is queried, so a frozen app can't stall it

What it does.

Everything you know from AltTab, plus the Dock behaviour from DockAltTab.

Hover previews

Rest on a running app's Dock icon and its windows appear right above it. Move up onto them and click one to switch.

Full-size window preview

With AltTab's "Preview selected window" turned on, pausing on a thumbnail shows that window at full size.

Windows-style clicks

Click an active app's icon to hide it, and click again to bring it back. Windows on other Spaces stay where they are, so clicking never switches Space.

Works with auto-hide

An auto-hiding Dock stays visible while you're in the previews. Your setting comes back on when you leave, even if AltTab crashed or was force-quit.

Still scriptable

The AppleScript commands from the scriptable AltTab (showApp, countAllWindowStats and the rest) still work, and now run the same code as the Dock previews.

Light on resources

It only checks what's under the pointer when the pointer is near the Dock. Everywhere else, mouse movement costs next to nothing.

Build it yourself.

There's no notarized download yet. Building takes a few minutes with Xcode installed.

Get the source

Clone this repository's dock-previews branch.

git clone -b dock-previews https://github.com/shredthaGNAR/alt-tab-dock-previews.git
cd alt-tab-dock-previews

Build

This signs the app ad-hoc, so you don't need an Apple developer certificate.

xcodebuild -workspace alt-tab-macos.xcworkspace -scheme Debug -configuration Debug -derivedDataPath ../DerivedData CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY="-" DEVELOPMENT_TEAM="" build

Run

Quit DockAltTab and any other AltTab first, then open the new build and grant Accessibility and Screen Recording when asked.

open ../DerivedData/Build/Products/Debug/AltTab.app

With ad-hoc signing, macOS treats every rebuild as a new app. Remove the old AltTab entry under System Settings → Privacy & Security → Accessibility before granting it again.

Settings.

Open AltTab's settings, then Controls → Additional controls… → Dock previews.

Show windows when hovering an app in the DockTurns Dock previews on or off.
Clicking an active app in the Dock hides itWindows-style toggle. Turn it off to keep the normal macOS Dock click.
Keep an auto-hiding Dock visible while previewingTemporarily turns off the Dock's auto-hide while you're in the previews.
Preview selected windowAltTab's own setting under Appearance. Also controls the full-size preview when you hover a Dock thumbnail.

Good to know.

  • The Dock drops magnification as soon as the pointer leaves it. That's macOS behaviour, and the previews stay where they first appeared.
  • With the click toggle on, you can't drag the Dock icon of an app that has open windows. DockAltTab behaves the same way.
  • DockAltTab's Ubuntu mode (click to preview), its preview-gap setting, and its Finder and Firefox picture-in-picture workarounds aren't included yet.
  • Only the macOS/Windows-style hover modes are ported. If you rely on the standalone DockAltTab app, it still works with this build over AppleScript. Just don't run both at once.
